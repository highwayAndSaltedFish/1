# 分诊路由

在 `check_red_flags` 已跑过、主诉和病程足够之后使用。只做就诊建议，不做诊断。

## 紧急程度

- **急诊 emergency**：红旗命中，或生命体征危象、活动性大出血、卒中样表现、严重呼吸困难、自杀自伤。告诉用户立刻急诊或呼叫急救，不要继续细问。
- **当天就诊 same-day**：高热不退、中重度疼痛、急性感染迹象、症状快速加重、孕妇不适但未达红旗、儿童精神尚可但家长担心明显。
- **常规门诊 routine**：轻症、病程平稳、无红旗、不影响进食睡眠和活动。

## 科室对照（常见主诉）

| 线索 | 优先科室 |
| --- | --- |
| 胸痛、心悸、水肿 | 心内科；红旗则急诊 |
| 咳嗽、气促、咯痰、哮喘 | 呼吸内科；呼吸困难则急诊 |
| 腹痛、反酸、呕吐、腹泻、黄疸 | 消化内科；急腹症/呕血则急诊或普外科 |
| 头痛、头晕、肢体无力、抽搐 | 神经内科；卒中样则急诊 |
| 外伤、骨折、关节肿痛、腰痛 | 骨科或急诊外科 |
| 皮疹、瘙痒、荨麻疹 | 皮肤科；过敏性休克则急诊 |
| 尿频尿痛、血尿、腰痛 | 泌尿外科或肾内科 |
| 月经、阴道出血、下腹痛 | 妇科；妊娠相关出血则急诊/产科 |
| 眼红、视力下降、眼痛 | 眼科；突发失明则急诊 |
| 耳痛、咽痛、鼻塞、听力下降 | 耳鼻喉科 |
| 儿童发热、咳嗽、腹痛 | 儿科 |
| 情绪低落、焦虑、幻觉、自杀观念 | 精神科/心理科；有自伤计划则急诊 |
| 无法归类的成人轻症 | 全科或普通内科 |

可给 1–2 个科室。不确定时写「优先…，备选…」。不要编造检查结果。
